# TaskFlow Pro 
### Personal Task Management & Placement Preparation Planner

TaskFlow Pro is a student-friendly web application that helps students manage daily tasks and prepare for placements in one place.

## Features
- Create, edit, and delete tasks
- Search and filter tasks
- Track pending and completed tasks
- Set task priorities, dates, and times
- Personalized welcome screen with motivational quotes
- Placement preparation resources for Python, Java, DSA, SQL, Aptitude, and Interviews
- Personal study schedule
- Colorful and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Objective
To help students organize their daily activities, track their progress, and access placement preparation resources through a single application.

## Project Type
Student Project — Task Management and Placement Preparation
